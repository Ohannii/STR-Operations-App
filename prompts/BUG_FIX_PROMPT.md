# BUG_FIX_PROMPT.md

We are in bug-fix mode only.

Read:
- docs/TASK_LOG.md
- docs/KNOWN_ISSUES.md
- docs/TESTING_CHECKLIST.md
- the files directly related to the bug

Then:
1. Restate the bug clearly.
2. State the expected behaviour.
3. State the most likely root cause.
4. Propose the smallest possible fix.
5. List exact files to change.
6. List regression risks.
7. List validation steps.

Do not refactor unrelated code.
Do not broaden scope.

After fixing, update:
- docs/CHANGELOG.md
- docs/KNOWN_ISSUES.md
- docs/TESTING_CHECKLIST.md
