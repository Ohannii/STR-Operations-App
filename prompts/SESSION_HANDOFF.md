# SESSION_HANDOFF.md

Create a clean handoff package for the next Claude session.

Include:
- current objective
- what was finished
- what is partially complete
- changed files
- exact next action
- known blockers
- tests already done
- tests still required
- rollback notes if relevant

Write it so a fresh session can continue without guessing.

Also update docs/TASK_LOG.md with the same handoff summary.
