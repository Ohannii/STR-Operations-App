Prepare for deployment, but do not deploy until checks are complete.

Read:
- docs/DEPLOYMENT_GUIDE.md
- docs/TESTING_CHECKLIST.md
- docs/KNOWN_ISSUES.md
- docs/CHANGELOG.md

Then:
1. Summarise release scope.
2. List unresolved issues that could block release.
3. List environment/config items to verify.
4. List required manual tests.
5. List rollback steps.
6. State whether this build is safe for preview only or safe for production.

Keep it explicit and beginner-friendly.
